# Analysis Pattern Library

## Method Selection

| Scenario | Method |
|----------|--------|
| Compare groups / periods | Comparative analysis |
| Change over time | Trend analysis |
| Multi-step conversion | Funnel analysis |
| User return behavior | Retention / cohort analysis |
| Credit assignment across touchpoints | Attribution analysis |

## Chart Selection Rules

- Trend over time -> line chart
- Category comparison -> bar chart
- Composition -> stacked bar / pie (few categories only)
- Follow the global `dataviz` skill (`agents/skills/analysis/dataviz.md`) for styling and palette

## Report Structure

- Conclusion first, then evidence
- State metric definitions per [[domain/metric-catalog]]
- Note data window, filters, and known caveats
